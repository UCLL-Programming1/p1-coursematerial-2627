This repository contains all the course material for `Programming 1`.

To get started, open the folder `0-intro`:
- `1-programming-intro` explains what you will learn in this course and what programming is about.
- `1-installation` contains the steps you need to follow to set up your computer to be able to use this course material. Make sure to follow them exactly as they are written.
- `2-how-to-use` then further describes how you can use this repository the way we intended.
